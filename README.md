# IC014: an audit of SING's null-space leakage score

This repo holds the code, committed result tables and the paper (`paper_workshop/main.tex`, TMLR format; `main.pdf`) auditing SING (arXiv 2603.14610, CVPR 2026).

**Main finding: SING's cross-model leakage ranking is indistinguishable from a null-energy ranking.** The null-energy fraction ρ alone reproduces SING's 13-model order as well as SING's own score (Kendall τ = 0.82 for both; paired difference CI [−0.36, 0.29]; partial τ 0.61 both ways, so neither subsumes the other).
Interventions (round 3, `r3/`): with SING's released translators, removing the same fraction of null energy from every model removes the agreement (τ = −0.03 / 0.09 on E12 / S11), and leak-free null content (image-independent Gaussian with each model's own mean and covariance; logits unchanged) still raises AS with energy on all 3 models tested and reproduces SING's order (τ = 0.69). So AS has a non-semantic path from null energy to the score; "confound" is used only in that sense. The order survives retrained ridge translators (τ = 0.85), but with them equal-energy AS keeps part of the agreement (τ = 0.61 / 0.75; 0.39 / 0.53 with a post hoc extended ridge grid), so the equal-energy result depends on the translator.
Second result: SING's "DinoViT" translator matches the supervised timm AugReg ViT-L/16; other public ViT-L/16 checkpoints are at chance. Secondary: size-corrected rankings differ from SING's but do not reverse it with confidence. Every pre-registered outcome is reported, including failures (E8 and E9 KILLs, tolerance stability, the ill-posed flatness rule, one BCa flag); see `RESULTS.md`.

## Layout
* `exp0b/` DinoViT identity (top-1 of five ViT-L candidates). `exp0/` digitisation of SING Supp. Fig. 12b (files keep an earlier name, `fig6b_*`) and null dims. `exp1/` within-model AS(d).
* `e1/` energy law; `e2/` 13-model ranking and claim audit; `e3/` planted-concept sensitivity; `e8/` null concept probe (pre-registered, KILL); `e9/` score screen (pre-registered, KILL).
* `r2/` round-2 analyses (`PREREG_R2.md`, `ROUND2_PLAN.md`); outputs in `r2/results/`. See `r2/README.md`.
* `r3/` round-3 analyses (`PREREG_R3.md`, `ROUND3_PLAN.md`): equal-energy interventions, leak-free null, retrained translators, PC bands vs the energy law, paired statistics, table generation. See `r3/README.md`.
* `paper_workshop/tables/` LaTeX tables and number macros generated by `r3/make_tables.py` (do not edit by hand).
* `gpu_jobs/` specs for work that needs ImageNet images or a GPU.
* `paper_workshop/archive/` earlier drafts.

## Reproduce
Environment: `python -m venv v && v/bin/pip install -r requirements.txt` (project-only pins, CPU torch; checked in a fresh venv). `requirements-lock.txt` is the old whole-machine freeze, kept for reference only.

* `make reproduce` (or `scripts/reproduce.sh`) regenerates every table, figure and number macro in the paper from **committed aggregate results** (round-2 summaries, `r3/results/F_paired_stats.json`, `paper_workshop/figs/`, `paper_workshop/tables/`, `paper_workshop/holdout_numbers.tex`). CPU, about 20 s. This checks consistency from aggregates only; it does not recompute anything from features. In a clean clone, `bash scripts/reproduce.sh && git diff --exit-code` passes.
* `make paper` builds the PDF with tectonic (`tectonic -X compile main.tex`).
* `make reproduce-full IC014_FEATS=/path/to/feats` reruns the feature-level analyses (rounds 2 and 3). It needs the private ImageNet features (checked by `scripts/verify_feats.sh` against `scripts/checksums.sha256`) and SING at commit e47b37d (`scripts/fetch_sing.sh`). There is no default feature path; a missing `IC014_FEATS` stops with an error. Per-image private outputs go to `IC014_PRIVATE` (default: the git-ignored `_private/`), never to the feature store.
  * Wall time on 8 CPU cores: a little over 2 h, most of it the E9 holdout (full run 1.95 h, about 7000 s); everything else takes about 15 min.
  * `make holdout-fast IC014_FEATS=...` runs the reduced holdout declared in `PREREG_R3.md` (N10): 5 draws instead of 20, 2 subspaces instead of 5, S9 dropped; resumable from its cache (checked: a run restarted from 40 of 64 cached cells skips them and ends with an identical cache and results). Timed on 8 cores: 36.3 min (target was under 30 min, missed). M1 and AS_SING Kendall means and all flatness verdicts are identical to the full run; AS_fair differs by +0.024 (linear) and +0.057 (nonlinear), and M1 − AS_fair by −0.024 / −0.057, so the nonlinear values miss the ±0.03 target. Use the full run for the paper numbers.
* **GPU work** (feature extraction; needs ILSVRC2012-val): two jobs were timed, Exp 1 features (1.4 GPU-h, one Kaggle GPU) and the fix-14 ViT-L/16 re-extraction (1.9 h on 2× T4 ≈ 3.8 GPU-h including weight downloads). The other extraction jobs were not timed; we estimate under 10 GPU-h in total. Specs are in `gpu_jobs/` (including the not-yet-run `gpu_jobs/r3_dino_vitb16.md`).

## Data
We do not redistribute ImageNet images or features derived from them (ImageNet terms of access).
The image lists are in `scripts/subset_files_10k.txt` (10 per class, file name and label) and `scripts/subset_files_claims200.txt`. Re-extracting the features requires your own copy of ILSVRC2012 val.
