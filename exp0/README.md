# Exp 0: CPU re-analysis of SING Supp. Fig. 6b

* `digitize_fig6b.py` digitizes Fig. 6b pixel by pixel. We rendered supplement p.5 at 800 dpi with `pdftoppm -r 800` and cropped it to `fig6b_800dpi.png`. The axis is calibrated on the 0/20/40/60 gridlines (linear fit, max residual 0.33). The reading error is ±0.38 ratio units: 2.5 px of edge/antialias uncertainty and the calibration residual, added in quadrature. Output: `fig6b_digitized.{csv,json}`.
* Limit: Fig. 6b only plots the *image-to-attribute ratio* (IS/AS), as 13 bars (the caption says "12 models"). Neither IS nor AS appears on its own, so AS vs null dim cannot be computed from this figure. Main-paper Fig. 3 gives IS and AS, but for 5 models only.
* `null_dims.py` computes m − rank(W) by SVD at tol 1e-5 (as in `sing/core/projectors.py`). 1×1-conv heads are flattened, the same way SING's wrapper does it. Output: `null_dims.{csv,json}`. `densenet_resnet_svcheck.py` → `sv_tolerance_check.json`.
* `stats.py` (seed 0, 10k permutations, two-sided) gives Spearman/Kendall of IS/AS vs null dim for all 13 models, without DinoViT, and leave-one-out. `stats.{csv,json}` uses the measured null dims; `stats_densenet24.{csv,json}` uses the plan's DenseNet = 24.
* Boring baseline (null-energy fraction ρ): not run here. It needs ImageNet features from all 13 models, which means forward passes on ImageNet-val. This box has no ImageNet, and the job needs a GPU.
